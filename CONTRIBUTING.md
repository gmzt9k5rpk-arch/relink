# Contributing

Thank you for contributing to relink_ai.

## Branch strategy

- Create a branch from `main` or `master`.
- Use a descriptive prefix such as `feature/`, `fix/`, or `chore/`.
- Keep branch names short and specific.

## Commit messages

Use concise commit messages in the format below:

```text
type: summary
```

Examples:

- `docs: add initial contributor guide`
- `chore: add baseline CI workflow`
- `fix: resolve build setup issue`

## Pull request checklist

- Describe the change clearly.
- Include testing steps.
- Link the relevant issue or task.
- Keep the change focused and reviewable.
